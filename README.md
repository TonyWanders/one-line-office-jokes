One joke about office life, written to a file by a small Python program,
for the make.fun bounty [One-Line Office Jokes](https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc).
The joke is fixed, so the output never changes between runs.

## The joke

```text
Our printer only jams when the deadline is near, which is why I now address it as sir.
```

86 characters, one line, inside the 1 to 199 gate.

## How to run it

```sh
python3 main.py
```

That writes the joke to `/output/entry.txt`. Give a path as the first
argument, or set `$OUTPUT_PATH`, to write somewhere else. The program
does nothing online and reads no clock: same input, same output, every
time.
